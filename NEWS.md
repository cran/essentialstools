# essentialstools 0.1.8

## Dataset updates

* Expanded the package to include 12 datasets.
* Added exercise, hummingbird, and intuition datasets.
* Retained previously available datasets.

## Included datasets

* `EVData` - Electric Vehicle Population Data
* `SearchData` - Interactive Search Data
* `SleepData` - Sleep Duration Data
* `balance_duration` - Balance Duration Data
* `birdRT` - Bird Reaction Time Data
* `blick` - Blick Data
* `exercise`
* `hummingbird`
* `illusion` - Illusion Data
* `intuition` - Intuition Data
* `music` - Music Business Survey Data
* `rapport` - Rapport Data
